# WebAssembly Parser Responsibilities

Rust supplies both the editable model and the byte spans used to save it. TypeScript has no separate JSON, XML or ENV grammar.

## API

- `parse_tree(type, text)` returns a recursive model with `key`, `path: string[]`, `kind`, exact display `value`, `span`, `quote`, and `children`.
- `update_value(type, text, path, value)` parses once, locates the field, preserves its original token type or quote style, and splices its value span.
- `edit_array(text, path, index?, value?)` removes a JSON array item when an index is supplied, or appends a JSON literal. Existing values and surrounding formatting are retained.
- `validate`, `validate_multi`, `register_schema`, `validate_schema`, and `validate_schema_with_id` provide syntax and JSON Schema validation.

`parser-wasm/pkg/parser_core.d.ts` is generated by wasm-bindgen from the Rust bindings and their TypeScript custom section. Frontend code imports this package directly; there are no ambient API copies. Result structs use serde serialization instead of property-by-property JavaScript object construction.

## Formats

| Format | Model and write behavior |
| --- | --- |
| JSON | Strict serde validation plus token spans; decoded object keys; array indices; exact numeric token text; original types on replacement. BOM is retained. |
| XML | Qualified names, matched closing tags, attributes, indexed repeated siblings, empty elements and CDATA. Parent indentation is never an editable value. Text padding and attribute quotes survive updates; escaping is specific to the value context. |
| ENV / properties / INI | String values, optional `export`, sections, BOM, CRLF, quotes and escaped or multiline values. `#` and `;` start unquoted inline comments only at the start of a value or after whitespace. Duplicate keys are indexed separately. |

Paths preserve literal segments: `['Logging','Microsoft.AspNetCore']`, `['servers','1','port']`, and `['configuration','appSettings','add','1','@value']`. Repeated sibling indices follow their element name. Duplicate JSON or ENV keys also gain an occurrence index.

The shared `BytePreservingParser` trait lives in `model.rs`. `positions.rs` centralizes UTF-8 byte spans and 1-based Unicode character columns, with explicit conversion for serde's byte columns. The default allocator is used. Release builds run wasm-opt with size optimization; schema validation disables HTTP and file resolution.

## Verification

`npm run test:rust` runs native parser tests and byte-for-byte edit regressions. `npm test` compiles the same crate for Node and runs the actual parse → form → update → write pipeline in JSDOM. CI runs these checks, formatting, Clippy with warnings denied, TypeScript checking, ESLint and a production build.
